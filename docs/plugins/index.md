# Optional Plugins

Zero's optional packages are installed and declared explicitly. Installing a
package alone does not expose routes or start another application.

- [Markdown documentation](./markdown-docs.md): folder-driven public docs with
  navigation, search, CodeBlock examples and shared design tokens.

Native server/plugin integration is documented in
[server extensions](../framework/phase-1-backend-extensions.md). The documentation
rebuild maintains its expanded plugin references under `docs-next/plugins/`;
that draft set does not automatically replace the currently shipped docs.
