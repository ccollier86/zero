# Agent Tooling Roadmap

[Tooling index](./index.md) · [Documentation index](../../index.md)

User-requested direction is a platform advanced coding agents can learn quickly
and compose safely, while remaining clear for developers.

- [ ] Compact task-oriented entry instructions with progressive feature loading.
- [ ] Source/export/version-verified capability metadata for search/routing and optional bundles.
- [ ] Evaluate AGENTS.md/engineering procedure integration without duplicating API manuals.
- [ ] Deliberate Codex/Claude hooks, reusable skills/scripts and fresh-agent validation tasks.
- [ ] Optional MCP tooling/gateway design with explicit authority and product boundaries.
- [ ] Production Markdown-first docs site with public-only projection and package/version alignment.

These are not installed tools. Current llm/llms files, CLI, Doctor and saved Git
release hooks already exist. Application [AI agents](../../backend/ai/agents.md)
and [Torrent](../../backend/torrent/index.md) are independent runtime features.

[Entrypoints](./entrypoints.md), [configuration](./configuration.md) and
[CLI roadmap](../../cli/tooling/roadmap.md) describe current versus future scope.
