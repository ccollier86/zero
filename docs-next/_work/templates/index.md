# Documentation Templates

These are authoring checklists, not descriptions of existing Zero features.
Adapt each template to the documented contract, retain applicable detail, and
replace all drafting prompts before review.
Rebase every relative link when copying a template to a new directory, replace
its parent-index backlink, and remove template-only instructions. Verify targets
and anchors after the copy.

[Working evidence index](../index.md) · [Documentation index](../../index.md)

- [System Inventory](./system-inventory.md): enumerate features, public
  surfaces, integration paths, evidence, findings, and documentation coverage.
- [Feature Guide](./feature-guide.md): explain a verified feature from its
  minimal example through configuration, authority, lifecycle, and next steps.

Use these with the [standards](../../documentation-standards.md) and
[process](../../documentation-process.md). Publishing a completed guide requires
the review gates; copying a template is not completion.
