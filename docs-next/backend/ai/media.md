# Images, Transcription And Speech

[Zero AI](./index.md) · [Providers](./providers.md) · [Documentation index](../../index.md)

Media operations use the same configured AIService but have separate typed
inputs, capability checks and fixed byte/result bounds. They do not automatically
upload generated content into Zero Storage or give an actor permission to read
an organization's source files.

## Image Generation

AIService.generateImage(AIGenerateImageRequest) returns Promise<AIImageResult>,
the bounded SDK image result. It defaults to the image alias.

Complete function with an app-bound service:

```ts
import type { AIService } from '@zero/framework/ai';

export async function makeIllustration(ai: AIService, prompt: string, signal?: AbortSignal) {
  const result = await ai.generateImage({ prompt, n: 1, abortSignal: signal });
  return result.images.map(image => ({
    bytes: image.uint8Array,
    mediaType: image.mediaType,
  }));
}
```

The result contains generated bytes; it is not a Zero drive/file ID. Authorize
the actor and persist bytes through the app's supported Storage service when
retention/sharing is appropriate.

prompt is a string or {images:AIDataContent[],text?,mask?}.
AIDataContent is string, Uint8Array or ArrayBuffer; it is not the transcription
URL type. Binary inputs are detached. Object prompts require1–16 input images.
Optional controls are n (default 1, integer 1–16), maxImagesPerCall (integer 1–16),
size (number x number string), aspectRatio (number:number string), seed,
maxRetries (integer 0–10), abortSignal, headers, providerOptions and metadata.
Size/aspectRatio support still depends on the selected model.

Image input has a 64MiB aggregate budget including prompt text/images/mask.
Generated images are nonempty and no more than requested; each is at most 64 MiB
and the aggregate is at most 256 MiB. Zero validates SDK/raw provider response
structure, warnings, metadata, result count and finite nonnegative usage values.
Invalid results use AI_PROVIDER_RESPONSE_INVALID; fixed byte violations use
AI_REQUEST_LIMIT_EXCEEDED.

## Transcription

AIService.transcribe(AITranscribeRequest) returns Promise<AITranscriptionResult>
and defaults to the transcription alias. audio accepts a base64/data-content
string, URL, Uint8Array or ArrayBuffer. Use an actual URL object for remote audio;
a plain string is treated as data content rather than a remote-download switch.

Options are model, maxRetries (integer 0–10), abortSignal, headers,
providerOptions, telemetry, download and metadata. There is no generation
timeout object on this API.

Complete function over already authorized bytes:

```ts
import type { AIService } from '@zero/framework/ai';

export async function transcribeAudio(ai: AIService, audio: Uint8Array, signal?: AbortSignal) {
  const result = await ai.transcribe({ audio, abortSignal: signal });
  return { text: result.text, segments: result.segments };
}
```

Raw/downloaded audio is bounded to 64 MiB; strings are bounded before SDK decode.
Default URL materialization uses Zero's DNS-pinned safe downloader. A custom
download callback is trusted server integration, not a user-supplied arbitrary
fetch capability; its returned Uint8Array is still detached and size-checked.

Transcription validates text/segment shapes, finite nonnegative times/duration,
segment start<=end, coherent response metadata and warnings. Combined transcript
and segment text is at most 16 MiB; at most 100,000 segments are admitted. A
plausible top-level transcript does not allow malformed hidden segment data.

## Speech Generation

AIService.generateSpeech(AIGenerateSpeechRequest) returns Promise<AISpeechResult>
and defaults to the speech alias. text is required; options are model, voice,
outputFormat (mp3/wav or provider string), instructions, speed, language,
maxRetries (integer 0–10), abortSignal, headers, providerOptions, telemetry and
metadata. Voices/formats/speed support remain model/provider-specific.

Complete function with an app-bound service:

```ts
import type { AIService } from '@zero/framework/ai';

export async function speak(ai: AIService, text: string, signal?: AbortSignal) {
  const result = await ai.generateSpeech({ text, outputFormat: 'mp3', abortSignal: signal });
  return result.audio.uint8Array;
}
```

Speech text is bounded to 1 MiB UTF-8 and optional instructions to 256 KiB.
Generated audio must be nonempty Uint8Array content at most 64 MiB, with coherent
provider response/warning metadata. Provider output bytes are validated before
the application treats them as a usable audio file.

## Errors, Storage And Observability

Provider credentials/settings stay server-only. Standard telemetry retains safe
provider/model/capability/timing/usage fields; media bytes, transcripts and raw
vendor metadata are not blanket public logging inputs. User-facing routes must
map AIError safely and protect file access/retention independently.

Inputs that are malformed use AI_REQUEST_INVALID, capacity failures use
AI_REQUEST_LIMIT_EXCEEDED, and invalid provider data uses
AI_PROVIDER_RESPONSE_INVALID. Explicit abort/timeout/provider failure use the
shared AI error classification, not a successful empty file.

These operations do not provision a drive, enforce your app's document retention,
or attach a foreign key to a user. Use the app-bound authorized data/storage
services for those actions, including tenant and API-key authority fences.

## Verification And Related Guides

Use local provider doubles to check input detachment, limits, malformed outputs,
cancellation, finite metadata/segment times and HTTP proxy endpoint selection.
A successful text provider does not prove image/audio capabilities. These guide
fragments were not sent to a live provider.
